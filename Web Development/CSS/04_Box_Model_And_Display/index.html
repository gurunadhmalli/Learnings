CSS Box Model and Display

Every HTML element is treated as a box. The box model explains how an element's content, padding, border, and margin use space. The display property controls how that box participates in the page layout.

1. The box model

From the inside out, an element is made of four parts:

Content
Padding surrounds the content. The yellow border surrounds the padding. Margin is the empty space outside the border.
Content
The text, image, or child elements inside the box.
Padding
Space between the content and the border.
Border
A visible line around the padding and content.
Margin
Space outside the border that separates this element from others.

2. Content-box and border-box

Both examples below have width: 220px, padding, and a border. The sizing rule changes what that width includes.

content-box The 220px width is only the content width. Padding and border are added outside it, so the visible box becomes wider.
border-box The 220px width includes the content, padding, and border, so the visible box stays 220px wide.

The usual practical choice is * { box-sizing: border-box; } because declared widths are easier to predict.

3. Block, inline, and inline-block elements

These examples use span elements so the effect of each display value is easy to compare.

display: block A block element starts on a new line and normally stretches across the available width. It accepts width, height, margin, and padding. display: inline An inline element stays within the current line. It does not start a new line, and width and height do not control it in the same way. display: inline-block Another inline-block An inline-block element stays beside other inline content, but accepts width, height, margin, and padding like a block.
Quick summary:
content-box adds padding and border to the declared size; border-box includes them. Block elements take a new line, inline elements share a line, and inline-block elements share a line while accepting box dimensions.
