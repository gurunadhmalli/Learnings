# Resources — curated, not exhaustive

The failure mode is collecting resources instead of using them. **Pick one per topic. Finish it.** Everything below is chosen because it's the best of its kind, not because it's popular.

Legend: 🆓 free · 💰 paid · ⭐ start here

## Math

## Datasets for projects

Avoid Titanic/Iris/MNIST for portfolio work — everyone has them.

- [Hugging Face Datasets](https://huggingface.co/datasets) · [Kaggle](https://www.kaggle.com/datasets) · [UCI ML Repo](https://archive.ics.uci.edu)
- [data.gov](https://data.gov) · [EU Open Data](https://data.europa.eu) · [World Bank](https://data.worldbank.org)
- [Google Dataset Search](https://datasetsearch.research.google.com)
- [Awesome Public Datasets](https://github.com/awesomedata/awesome-public-datasets)
- **Best option:** collect your own. Scrape a niche, use an API, label 500 examples by hand. It instantly differentiates your portfolio.

## Compute on a budget

- **Google Colab** (free tier + Pro) — start here
- **Kaggle Notebooks** — 30 GPU hrs/week free
- **Lightning AI Studios** — generous free tier
- **Vast.ai / RunPod / Lambda Labs** — cheapest per-GPU-hour rentals
- **Modal / Replicate / Baseten** — serverless GPU for inference
- Cloud free credits: AWS/GCP/Azure new-account tiers
- Local: a used RTX 3090 (24GB) is the best value for serious local work
